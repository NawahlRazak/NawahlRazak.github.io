EM97 - LRC Resonance

Shows self-inductance using an LRC circuit.

This apparatus consists of an LRC circuit prewired in a lunchbox with a variable Capacitor and some loose components to set up various other LRC circuit combination. Use together with a function generator and Oscilloscope tp study the resonance frequencies obtained with different L,R, and C parameters.
